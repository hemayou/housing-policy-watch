# 住房政策观察 · Housing Policy Watch

跟踪、归档并深度研究中国住房与房地产政策的公开仓库。

**📖 在线阅读主报告**：[风险重估：828 房地产新政研究](https://hemayou.github.io/housing-policy-watch/)

## 缘起

2026 年 8 月 28 日晚，住房城乡建设部、中国人民银行、国家金融监督管理总局、中国证监会等多部委集中发布五份政策文件，系统重构房地产开发、融资、销售的基础制度——预售制走向现房销售、开发信贷转向主办银行制与封闭管理、融资逻辑从主体信用转向项目信用。本仓库以此为起点，做政策原文归档与深度研究。

## 仓库结构

```
policies/    政策原文归档（公开发布的官方文件，Markdown 整理版）
research/    研究素材——笔记、公开数据、观点索引
reports/     深度研究报告（HTML，主报告 + 子专题）
scripts/     数据整理与页面构建脚本
site/        网站发布目录（GitHub Pages）
```
